# სტანდარტული ტურების კატალოგი

## შედეგი

სტანდარტული ტურების რაოდენობა გაიზარდა 7-დან 31-მდე. კატალოგს დაემატა ორი დამოუკიდებელი ფილტრი — `hiking` და `history` — და ყველა ახალი ტური ხელმისაწვდომია ექვს ენაზე.

## თემატური ჯგუფები

| ჯგუფი | ახალი ტურები |
|---|---|
| ისტორიული | თბილისის ისტორიული ფენები; მცხეთა–უფლისციხე–ატენი; სამცხე-ჯავახეთის დიდი ისტორიული გზა |
| კულინარიული | კახური სუფრა და მარანი; იმერული და მეგრული გემოები |
| ღვინო | რაჭის ღვინო და მთის სამზარეულო |
| ველო | კახეთის ველო და ღვინის გზა; ბორჯომის ველო და ბუნების წრე |
| ჰაიქინგი | ყაზბეგის ჰაიქინგის ბაზა; სვანეთის სოფლების ტრეკი; თუშეთის მაღალმთიანი ჰაიქინგი |
| ბუნება | აჭარა-გურიის მწვანე გზა |
| ოჯახური | იმერეთი ოჯახთან ერთად |
| კლასიკური | საქართველოს დიდი კლასიკური ტური |

მეორე ეტაპზე დამატებულია კიდევ 10 მარშრუტი: თბილისის არქიტექტურა და ბაზრები; ქვემო ქართლის არქეოლოგიური გზა; შიდა ქართლის მონასტრების ბილიკი; ჯავახეთის ტბები და ფრინველები; სამეგრელოს სამეფოები და ჭარბტენიანი ბუნება; რაჭის ალპური ჰაიქინგი; ზემო აჭარის ღვინო და სოფლები; გურიის ნელი კულინარია და ზღვა; სვანეთის ალპური წრე; ოჯახური საქართველო შვიდ დღეში.

## დაგეგმვის პრინციპები

- გაჩერებები დალაგებულია გეოგრაფიული მიმართულებით და არა პოპულარობის მიხედვით.
- მრავალდღიან ტურში გათვალისწინებულია ღამის ბაზა და გრძელი მართვის დღეების შემცირება.
- რთულ გზებზე მითითებულია SUV/4x4 და სეზონური შეზღუდვა.
- თუშეთისა და სვანეთის რთულ მონაკვეთებზე პირდაპირაა მითითებული ადგილობრივი მძღოლის ან გამყოლის საჭიროება.
- ველოტურები ითვალისწინებს თანმხლებ მანქანას და რთულ/სახიფათო მონაკვეთებზე ტრანსფერს.
- ღვინის ტურებში მძღოლისთვის ალკოჰოლის არდაგემოვნების წესი ცალკეა აღნიშნული.

## უსაფრთხოების შენიშვნა

სტანდარტული ტური არის დაგეგმვის შაბლონი და არა გზის გახსნილობის გარანტია. მაღალმთიანი გზის, ბილიკის, ამინდის, დაცული ტერიტორიის რეჟიმისა და ტრანსპორტის მდგომარეობა გამგზავრების დღეს უნდა გადამოწმდეს.

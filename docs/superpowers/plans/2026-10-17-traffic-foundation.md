# Traffic Foundation (sub-project 1) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make rentup.ge measurable and listable:
- cookieless Umami analytics with call, WhatsApp and booking events;
- one source of truth for the business location(s), with per-branch JSON-LD and a contact-page list;
- a generated marketing pack (listing copy, UTM rules, review-request templates, owner steps) and a fleet export for aggregators.

**Architecture:**
- **Analytics.** `static/analytics.js` keeps its public `window.RentUpAnalytics` interface (`track`, `once`, `carParams`, `bookingParams`), but its backend changes from GA4 to Umami. The build injects the Umami tag only when a website id is configured.
- **Branches.** Locations move into `content/settings/branches.yml`. `build.py` reads them for JSON-LD and the contact page.
- **Marketing output.** The docs and the fleet CSV are generated by scripts from existing content files, so no fact is typed twice.

**Tech Stack:** Python 3 static generator (`build.py`, PyYAML, `yaml_io`), vanilla JS, `unittest` + node test harness (`tests/*.test.js` run via a `tests/test_*_js.py` wrapper), Umami Cloud.

**Spec:** `docs/superpowers/specs/2026-10-17-traffic-foundation-design.md`

## Global Constraints

- **Analytics provider:**
  - Umami Cloud only. No GA4, no cookies, no consent banner.
  - Tag: `<script defer src="https://cloud.umami.is/script.js" data-website-id="<UUID>"></script>`.
  - Empty id means no analytics markup on any page.
- **Event names, exactly:** `call_click`, `whatsapp_click`, `booking_request`. Each event carries `lang` and `page_type`.
- **UTM vocabulary, exactly:**
  - `utm_source` ∈ {`gbp`, `yandex-maps`, `2gis`, `apple-maps`, `localrent`, `discovercars`, `partner-<slug>`, `ads-<lang>`};
  - `utm_medium` ∈ {`maps`, `aggregator`, `referral`, `cpc`};
  - `utm_campaign` is free text.
- **Business name** on every listing is exactly `RentUp`. No keywords appended.
- **Branches:**
  - Only staffed physical offices are branches. Airports and delivery points go in `areaServed`, never as a branch.
  - Initial data has one branch: 71 Vazha-Pshavela Ave., Tbilisi, 0186; lat 41.7245, lon 44.7509; 09:00–21:00 daily; +995597555565.
- **Reviews:** never fabricate. Never offer a reward for a review.
- **Owner-only actions:** creating accounts, verifying listings, signing aggregator contracts. Claude never creates accounts or enters passwords; these steps are only documented.
- **Aggregator order:** Localrent first, DiscoverCars second.
- **Copy limits:**
  - Google Business Profile description ≤ 750 characters per language;
  - all 6 languages present: ka, en, ru, fa, he, ar.
- **Every release:**
  - `python build.py --validate-only`;
  - `python build.py dist`;
  - `python -m unittest discover -s tests`;
  - `python scripts/seo_audit.py dist` → 0 errors.

## Review Focus

1. **Umami blocked by an ad-blocker, or still loading, when a user taps "call".** `RentUpAnalytics.track` must return `false` silently, never throw, and the `tel:` / `wa.me` navigation must proceed. Test in Task 2.
2. **Tap lands on a child of the link** (`<span>☎</span>`, `<bdi>` inside the `<a>`). The event must still fire once, via `closest("a")`. Test in Task 2.
3. **RTL / non-Latin pages (he, ar, fa).** `lang` in the event must equal `<html lang>` (`he`, not `en`). Test in Task 2.
4. **`branches.yml` missing or empty.**
   - The build must not crash.
   - `org_node()` keeps its current address from `site.yml`.
   - The contact page simply omits the list.
   - Test in Task 3.
5. **A car with a blank or non-numeric price tier** (prices are strings, e.g. `''`, `'310'`). The fleet export must skip that cell, list the car in a warnings line, compare numbers as `int`, and not crash. Test in Task 5.

- Create: `tests/test_analytics_js.py`. Copy of `tests/test_catalogue_js.py`, pointing at `analytics.test.js`; skips when `node` is missing.

**Interfaces:**
- Consumes: Task 1's tag, so `window.umami` may exist.
- Produces: `window.RentUpAnalytics = {enabled, track(name, params) -> bool, once(key, name, params) -> bool, carParams(el), bookingParams(root)}`.
  - `track` calls `window.umami.track(name, clean({...params, lang, page_type}))` when `window.umami && typeof window.umami.track === "function"`. Otherwise it returns `false`.
  - `lang` = `document.documentElement.lang`.
  - `page_type` = first `page-(\S+)` match in `document.body.className`, else `"other"`.
  - A single delegated `click` listener on `document`:
    - `a[href^="tel:"]` → `track("call_click", {href_kind: "tel"})`;
    - `a[href*="wa.me/"]` → `track("whatsapp_click", {})`.
    - Resolve the anchor via `event.target.closest("a")`. Never call `preventDefault`.
  - Remove: gtag bootstrap, `page_view`/`car_view` GA calls. Umami records page views itself.

  - `click on a <span> inside a tel: link fires call_click exactly once`;
  - `click on a wa.me link fires whatsapp_click`;
  - `click on an ordinary link fires nothing`;

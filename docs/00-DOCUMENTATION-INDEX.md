## HTML ვერსიები

Markdown არის ერთადერთი წყარო. HTML ვერსიები **გენერირდება** და ხელით არ უნდა შეიცვალოს — ცვლილება შემდეგივე გაშვებაზე დაიკარგება.

```
PYTHONIOENCODING=utf-8 python scripts/build_docs_html.py
```

სკრიპტი `docs/*.md`-ს და repo-root-ის ძირითად დოკუმენტებს (README, AUDIT, RESEARCH, IMPLEMENTATION_*, ADMIN_SETUP, FIREBASE, ATTRACTION_SPEC) გარდაქმნის `docs/*.html`-ად, ბმულებს ავტომატურად გადაამისამართებს და `index.html`-ს ინდექსის ასლად ინახავს ძველი bookmark-ებისთვის.

გაუშვით docs/-ში ნებისმიერი ცვლილების შემდეგ.

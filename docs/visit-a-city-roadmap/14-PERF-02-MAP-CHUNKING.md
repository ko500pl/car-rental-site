# PERF-02 — რუკის მონაცემების ნაწილობრივი ჩატვირთვა

სტატუსი: **დასრულდა**  
დასრულების თარიღი: **2026-08-21**  
პრიორიტეტი: **P0**

## შედეგი

რუკის საწყისი ფაილი აღარ შეიცავს ადგილების სრულ, მძიმე აღწერებსა და სურათების
მონაცემებს. გახსნისას იტვირთება საქართველოს მასშტაბის მსუბუქი ინდექსი, ხოლო
ადგილის სრული ინფორმაცია იტვირთება მოთხოვნისას შესაბამისი რეგიონული ფაილიდან.

## განხორციელებული ცვლილებები

- თითოეული ენისთვის შეიქმნა 11 რეგიონული JSON ფაილი — სულ 66 ფაილი.
- საწყის ინდექსში დარჩა მხოლოდ ძიების, ფილტრაციის, შეფასებისა და რუკაზე
  განთავსებისთვის საჭირო ველები.
- `PLANNER_DATA`-დან ამოღებულია ადგილების მეორე, დუბლირებული კატალოგი.
- რუკის გადაადგილებას დამატებული აქვს 180 ms დაყოვნება, რათა სწრაფი მოძრაობისას
  ზედმეტი მოთხოვნები არ გაიგზავნოს.
- ახალი გადაადგილება აუქმებს ძველ მოთხოვნას; დაგვიანებული პასუხი ახალ მდგომარეობას
  ვეღარ გადაფარავს.
- უკვე არსებული მარკერი სრული მონაცემის მიღებისას ადგილზე მდიდრდება და არ
  დუბლირდება.
- მიღებული რეგიონული ფაილები ინახება ბრაუზერის ადგილობრივ ქეშში; ქსელის დროებითი
  შეფერხებისას გამოიყენება ბოლო წარმატებული ასლი.
- zoom 8-დან დაჯგუფებაში შედის მხოლოდ ეკრანზე ხილული არე და 18%-იანი უსაფრთხო
  ზოლი, ამიტომ ეკრანს გარეთ დარჩენილი წერტილები cluster-ის რიცხვს აღარ ზრდის.

## მონაცემთა ნაკადი

1. გვერდი იღებს მსუბუქ, ქვეყნის მასშტაბის ინდექსს და რეგიონების manifest-ს.
2. zoom 8-მდე რეგიონული მძიმე ფაილი არ იტვირთება.
3. zoom/pan-ის შემდეგ განისაზღვრება ხედთან გადაკვეთილი რეგიონები.
4. მოთხოვნილი რეგიონი ერთჯერადად იტვირთება და ქეშდება.
5. სრული ჩანაწერები შესაბამის საწყის ობიექტებს უერთდება უნიკალური `slug`-ით.
6. ადგილის/ტურის პირდაპირ არჩევისას საჭირო რეგიონი იტვირთება ხედის მოძრაობის
   ლოდინის გარეშეც.

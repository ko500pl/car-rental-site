- წყარო ფაილებია `sitegen/`, `static/`, `content/`, `admin/`, `mobile/` და `tests/`; გენერირებულ `dist*` ფაილებში ხელით ცვლილება აკრძალულია.
- ახალი ფუნქცია უნდა მუშაობდეს ექვსივე ენაზე ან ჰქონდეს მკაფიო fallback.
- მომხმარებლისთვის ნაჩვენები backend/SDK შეცდომა უნდა გადაითარგმნოს ადამიანურ ტექსტად.

- მონაცემთა ცვლილება უნდა იყოს ვალიდირებადი და ადმინიდან მართვადი, სადაც ეს ბიზნესის მოთხოვნაა.
- ახალი გარე სერვისი არ დაემატოს API ფასის, privacy-ისა და fallback-ის აღწერის გარეშე.

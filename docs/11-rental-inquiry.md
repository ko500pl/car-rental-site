# გაქირავების მოთხოვნა და WhatsApp

## ნაკადი

ტურისტული კონტენტი → მანქანის რეკომენდაცია → მოკლე მოთხოვნის ფორმა ან WhatsApp → ოპერატორის პასუხი.

## ფორმა

მთავარ, ავტოპარკის, რუკის/დამგეგმავისა და შესაბამის ტურისტულ გვერდებზე ჩანს კომპაქტური ფორმა: აღების ადგილი, თარიღები, სახელი, ტელეფონი და შენიშვნა. მანქანის გვერდი დამატებით ინახავს კონკრეტულ მანქანას, დაბრუნების ადგილს, მგზავრებსა და ფასის შეფასებას.

## WhatsApp

ნომერი მოდის `content/settings/site.yml`-დან. ტექსტში გადადის გვერდი, კონტექსტი, მანქანა, თარიღები, ადგილი და ხანგრძლივობა. ნომერი კოდში არ არის ჩაშენებული.

## ფორმის fallback

ფორმა არის Netlify Forms-compatible და Firebase-ს არ საჭიროებს. ეს არის მოთხოვნა და არა ავტომატურად დადასტურებული ჯავშანი.

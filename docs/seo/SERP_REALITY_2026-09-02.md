# SERP Reality Check — where #1 is winnable for rentup.ge (2026-09-02)

**Method.** 41 live searches on 2026-09-01/02 (35 requested queries + 6 verification queries). Organic results only: no map pack, no ads, not geo-localised to Georgia / Israel / Iran / the Gulf, so real SERPs in those markets differ at the margins. Treat every score as directional until Search Console has data. **rentup.ge appeared in zero of 41 result sets, including the brand query `rentup.ge car rental`** — consistent with the site having no authority at all yet.

**Page types.** OTA = Expedia / Booking / Skyscanner / Kayak; AGG = supplier aggregator (Localrent, Discover Cars, OneClickDrive, VIP Cars, Rentalcars); GLOBAL = SIXT / Avis / Enterprise / Europcar / Alamo; LOCAL = Georgia-based rental company; CLASS = classifieds / directory; BLOG = editorial; UGC = forum / Facebook / Quora / Tripadvisor; BROKER = foreign (Israeli, Iranian) travel broker reselling Georgian cars.

**Winnability (for #1, 3–6 months, zero links):** 1 = no; 2 = top-10 possible, #1 not; 3 = top-3 realistic with a dedicated page + a handful of links; 4 = #1 realistic with a purpose-built page; 5 = SERP effectively empty or broken — #1 on publication.

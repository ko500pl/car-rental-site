## პირდაპირი დიაგნოზი

ამ სესიაში გაკეთებული ყველაფერი — 2 358 გვერდი, schema, სიჩქარე, შიდა ბმულები, ქართული ენა — **შესვლის ბილეთია, არა მოგება.** Google-ს ეს ეუბნება „ეს საიტი გასაგებია და ტექნიკურად სწორია". არ ეუბნება „ეს საიტი სანდოა და პასუხის ღირსია".

ვნახე სამი კონკრეტული რამ, რაც ხსნის ბოლო ადგილს:

**1. Google-ს არავის უთქვამს, რომ ეს საიტი არსებობს.**
`rentup.ge`-ზე არ არის არც Search Console-ის დამადასტურებელი კოდი, არც Bing-ის, არც Yandex-ის. ანუ არავინ იცის, გვერდები საერთოდ ინდექსშია თუ არა, რამდენჯერ გამოჩნდა, რომელ სიტყვაზე. **ბრმად ვმუშაობთ.**

**2. ანალიტიკა გამორთულია.**
GA4-ის იდენტიფიკატორი ცარიელია — ყოველ deploy-ზე ანალიტიკა ითიშება. ვიზიტორების რაოდენობაც კი არ ვიცით.

**3. კონკურენტები სხვა წონით თამაშობენ.**
„car rental Tbilisi"-ზე პირველ გვერდზე არიან: Expedia, SIXT, Enterprise, Localrent, wander-lush.org, GSS, GeoDrive. ესენი წლებია არსებობენ და ათასობით გარე ბმული აქვთ. ახალ დომენს მათთან პირდაპირი შეჯიბრი 12 თვეშიც არ მოუგია — და ეს ნორმალურია, არა მარცხი.

**რაც აკლია, არის არა კიდევ ერთი გვერდი, არამედ სამი რამ: გაზომვა, ადგილობრივი თანდასწრება და გარე ბმულები.**

## რა უნდა გააკეთო შენ, ამ თანმიმდევრობით

### 1. Google Business Profile — უფასო, ~20 წუთი, ყველაზე დიდი ეფექტი

„მანქანის ქირაობა თბილისში"-ზე კლიკების უდიდესი წილი **რუკის ბლოკს** მიაქვს, არა ჩვეულებრივ შედეგებს. იქ მოხვედრა ბმულებზე არ არის დამოკიდებული — საჭიროა დადასტურებული პროფილი. ეს არის ერთადერთი ადგილი, სადაც ახალ საიტს დღესვე შეუძლია გამოჩნდეს.

`business.google.com` → ყველა მონაცემი მზადაა:

| ველი | მნიშვნელობა |
|---|---|
| სახელი | RentUp (რენტაპი) |
| კატეგორია | Car rental agency (ძირითადი) |
| მისამართი | ვაჟა-ფშაველას გამზირი 71, თბილისი 0186 |
| კოორდინატები | 41.7245, 44.7509 |
| ტელეფონი | +995 597 55 55 65 |

| სერვისის ზონა | თბილისი, ქუთაისი, ბათუმი + სამივე აეროპორტი |

დადასტურება ღია ბარათით ან ვიდეოთი ხდება — მოამზადე ოფისის, ნიშნის და რამდენიმე ავტომობილის კადრი.

### 2. Search Console + Bing — უფასო, ~10 წუთი

1. `search.google.com/search-console` → Add property → `https://rentup.ge` → **HTML tag** მეთოდი → დააკოპირე `content="..."`-ის შიგთავსი
2. მომწერე კოდი — ჩავწერ `site.yml`-ში და გავუშვებ deploy-ს
3. დადასტურების შემდეგ: Sitemaps → `sitemap.xml`
4. იგივე `bing.com/webmasters` — Search Console-იდან იმპორტი ერთი ღილაკია

**ამის შემდეგ პირველად დავინახავთ რეალურ სურათს:** რამდენი გვერდია ინდექსში, რომელ სიტყვაზე ვჩნდებით, სად ვართ 20-ში და ერთი ბიძგი გვჭირდება.

### 3. აგრეგატორებში შესვლა — ფული შემოაქვს დღესვე

Localrent, Discover Cars, Myrentacar, EconomyBookings — ესენი ჩვენს კონკურენტებად რომ ჩავთვალეთ, სინამდვილეში **მიმწოდებლებს აგროვებენ.** მათში შესვლა ორ რამეს აკეთებს: ჯავშნებს გიგზავნის ახლავე, და ბმულს/ხსენებას გიქმნის, რაც Google-ისთვის სანდოობის სიგნალია.

ეს არის ყველაზე სწრაფი გზა შემოსავალამდე, სანამ ორგანული ძებნა ამუშავდება.

### 4. ქართული ბმულები — ნელა, მაგრამ ეს არის მთავარი განსხვავება

გამოქვეყნებული 2 358 გვერდი მხოლოდ მაშინ დაიწყებს რანჟირებას, როცა სხვები დაიწყებენ მასზე მითითებას. კონკრეტულად რაც მუშაობს:

- სასტუმროები და გესთჰაუსები, რომლებთანაც თანამშრომლობ — „ტრანსპორტი" გვერდზე ბმული
- ქართული ტურისტული კატალოგები და ბიზნეს-დირექტორიები
- `/guides/` — „გჭირდებათ თუ არა ჯიპი", 267 ადგილის რეალურ მონაცემებზე აშენებული — ერთადერთი, რასაც კონკურენტი ვერ დააკოპირებს. ეს არის ის, რასაც ბლოგერი ან ფორუმი ბუნებრივად დაალინკავს. გაავრცელე იქ, სადაც საქართველოში მოგზაურობაზე საუბრობენ.

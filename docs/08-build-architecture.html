გადაწყვეტილება

შაბლონები

templates/pages-ში თითო გვერდის ტიპს ექნება საკუთარი HTML: fleet, car, pricing, planner, map, region, attraction, route, blog და სხვა. საერთო header/footer/base ნაწილები partial-ებად რჩება.

მიგრაცია

ეტაპობრივი ჩანაცვლება: ჯერ URL/კონტენტი/ვალიდაცია, შემდეგ shell და SEO, მერე მარტივი გვერდები, ავტოპარკი, მოგზაურობის მოდულები და ბოლოს sitemap/llms. ყოველ ეტაპზე ძველი და ახალი შედეგები შედარდება.

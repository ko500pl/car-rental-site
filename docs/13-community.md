# ჯგუფები, შეტყობინებები და შეფასებები

ეს ფუნქციები Firebase/Firestore/Storage-ის რეალურ კონფიგურაციას საჭიროებს. გათიშულ მდგომარეობაში ძირითადი ტურისტული და გაქირავების ფუნქციები მუშაობას აგრძელებს. მომხმარებლის მიერ ატვირთული ფოტო და ტექსტი არ გარდაიქმნება კომპანიის ყალბ testimonial-ად ან JSON-LD Review-ად.

production-ში საჭიროა ownership წესები, ფაილის MIME/ზომის შეზღუდვა, report/moderation პროცესი და privacy/retention პირობები.

ავტოგაქირავების ვებგვერდი + ადმინ-პანელი + საქართველოს ტურისტული რუკა

ექვსენოვანი სტატიკური საიტი ადმინ-პანელით. მთელი კონტენტი — ტექსტი, ფასები, ავტომობილები ფოტოებით, ბლოგი, 82 ღირსშესანიშნაობა, 11 რეგიონი, 7 მარშრუტი, ბრენდი და დიზაინის პარამეტრები — იმართება /admin/-იდან ბრაუზერიდან.

  • 786 გვერდი = (10 გვერდი + 17 ავტომობილი + 4 სტატია + 11 რეგიონი + 82 ღირსშესანიშნაობა + 7 მარშრუტი) × 6 ენა
  • ენები: ქართული · English · Русский · فارسی · עברית · العربية (ბოლო სამი RTL)
  • Google-ისა და AI-ძიების (ChatGPT, Perplexity, Claude, Gemini) ოპტიმიზაცია
  • ადმინი — Decap CMS: ცვლილება იწერება GitHub-ში, საიტი თავად გადაიწყობა 1–2 წუთში

JavaScript მხოლოდ რუკის გვერდებზეა (Leaflet, ლოკალურად ჩადებული). კომერციული გვერდები — მთავარი, ავტოპარკი, ფასები, პირობები, FAQ, კონტაქტი — სრულიად JS-ის გარეშეა.

1. სწრაფი დაწყება

pip install -r requirements.txt
python3 build.py dist
python3 -m http.server 8000 --directory dist

მონაცემების ცალკე შემოწმება:

python3 build.py --validate-only
python3 build.py dist --strict

--strict განკუთვნილია საჯარო გამოქვეყნებისთვის: build შეჩერდება placeholder კონტაქტების, დაკარგული ავტომობილის ფოტოების, არასრული ექვსენოვანი ტექსტის ან გატეხილი რეგიონი/ღირსშესანიშნაობა/მარშრუტის კავშირის აღმოჩენისას. ახალი ავტომობილი, რეგიონი, ღირსშესანიშნაობა და მარშრუტი ადმინში draft სტატუსით იქმნება; საჯაროდ მხოლოდ published ჩანაწერი ჩანს, ხოლო archived ინახება და საიტიდან იმალება.

ადმინის ლოკალური ტესტი (GitHub-ის გარეშე):

npx decap-server          # ცალკე ტერმინალში
# → http://localhost:8000/admin/  →  "Login"

2. გაშვება: ნაბიჯ-ნაბიჯ

ნაბიჯი 1 — GitHub რეპოზიტორია

git init && git add . && git commit -m "car rental site"
git branch -M main
git remote add origin https://github.com/<user>/<repo>.git
git push -u origin main

რეპოზიტორია შეიძლება იყოს პრივატული — ადმინი ორივე შემთხვევაში მუშაობს.

ნაბიჯი 2 — Netlify

Netlify → Add new site → Import an existing project → აირჩიეთ რეპოზიტორია. Build command და publish directory ავტომატურად აიღება netlify.toml-იდან. შემდეგ Domain settings → დაამატეთ დომენი (SSL ავტომატურია).

ნაბიჯი 3 — ადმინის ავტორიზაცია

  1. GitHub → Settings → Developer settings → OAuth Apps → New OAuth App - Homepage URL: https://<თქვენი-დომენი> - Authorization callback URL: https://api.netlify.com/auth/done
  2. Netlify → Site configuration → Access control → OAuth → Install provider → GitHub → ჩასვით Client ID და Secret.
  3. admin/config.yml → backend.repo: <user>/<repo>
  4. Push → https://<დომენი>/admin/ → Login with GitHub

ნაბიჯი 4 — მომხმარებლების დამატება

GitHub → რეპოზიტორია → Settings → Collaborators → Add people → role: Write. ცალკე პაროლები არ არსებობს; ყოველი ცვლილება Git-ის ისტორიაშია (ვინ, როდის, რა).

6. ძიებაში აღმოჩენადობა

Google

  • უნიკალური title და description ყველა 786 გვერდზე — ავტომატურად შემოწმებული

  • sitemap.xml — 786 URL, თითოს ექვსენოვანი xhtml:link ალტერნატივებით
  • JSON-LD @graph: AutoRental + LocalBusiness, WebSite, WebPage, BreadcrumbList, FAQPage, OfferCatalog, SoftwareApplication, Car, BlogPosting, TouristAttraction (კოორდინატებით), TouristDestination, TouristTrip (მარშრუტის იტინერარით), ItemList

9. ტექნიკური შენიშვნები

ბლოკების ტიპები (ადმინში „Add ბლოკი“): H2/H3, აბზაცი, ყურადღების ბლოკი, სია, დანომრილი სია, ცხრილი, ციფრების ზოლი, ბარათები, FAQ, CTA, ავტომობილების ბადე. ტექსტში მუშაობს **მსხვილი** და [ბმული](/pricing/) — ენის პრეფიქსი ავტომატურად ემატება.

ახალი ენის დამატება: build.py → ALL_LANGS, LANG_LABEL, LANG_SHORT, OG_LOCALE, LANG_DIR, fmt_date; საჭიროებისას LANG_FONT. შემდეგ ყველა content/**/*.yml-ს დაამატეთ ახალი ენის ბლოკი. LANGS თავად გამოითვლება იმ ენებით, რომლებზეც სრული თარგმანია — ნახევრად თარგმნილი ენა ბილდს არ ტეხს.

ალტერნატიული ადმინი: admin/index.html-ში კომენტარშია Sveltia CMS — იგივე config.yml, უფრო სწრაფი ინტერფეისი.

ანალიტიკა ჩაშენებული არ არის. Netlify Analytics ან Cloudflare Web Analytics სერვერული მხრიდან მუშაობს და გვერდს არ ამძიმებს.

# SEO და სოციალური გაზიარება

ყოველ გვერდს აქვს canonical, ექვსენოვანი hreflang, title/description, breadcrumb და JSON-LD. sitemap-ის `lastmod` გამომდინარეობს წყარო ფაილის modification date-იდან და არა ყოველი build-ის დღიდან.

ექვსივე ენისთვის არსებობს OG fallback. Car/Offer schema იყენებს რეალურ ადმინისტრაციულ GEL ფასსა და ხელმისაწვდომობას. ყალბი AggregateRating/Review schema არ გენერირდება.

ფლოტის რაოდენობა უნდა გამომდინარეობდეს გამოქვეყნებული ჩანაწერებიდან; ძველი „120+“ განცხადებები აკრძალულია რეგრესიის ტესტით.

# ადმინისტრაცია და წვდომა

## მისამართი

ადმინისტრაცია იხსნება `/admin/`-ზე. კონტენტი ინახება Git რეპოზიტორიაში და იმართება Decap CMS-ით.

## უსაფრთხო წვდომა

რედაქტორს სჭირდება GitHub repository-ზე Write/Admin უფლება და ჰოსტინგში გამართული GitHub OAuth. პაროლი, Client Secret ან Firebase გასაღები კოდში არ იწერება.

## სამუშაო პროცესი

ახალი ჩანაწერი იწყება `draft` სტატუსით. `published` ჩანს საიტზე; `archived` რჩება ადმინისტრაციაში და საჯაროდ იმალება. გამოქვეყნებამდე საჭიროა ექვსივე ენა, სწორი reference-ები, რეალური კონტაქტები და მანქანის მთავარი ფოტო.

ზუსტი არატექნიკური ნაბიჯები მოცემულია [ADMIN_SETUP.md](../ADMIN_SETUP.md)-ში.
